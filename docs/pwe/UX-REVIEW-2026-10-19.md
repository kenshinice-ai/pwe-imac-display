# 发送端设置界面审查（2026-10-19）

> 只读审查，对象是 `pwe-1.1` 7bb9851（2026-10-19 16:43）。起因：Lee 在真机基线时觉得发送端的设置部分「很奇怪」。
> 这个提交里，主窗口已经有「画面」菜单（标准 1440p / 5K 48 / 5K 60），按 iMac 记住选择；未在真机上验证。

## 一、主要问题

1. **设置分在三个窗口，「关于」有三个。** 主窗口顶部只有 ⓘ 和「高级设置…」（`PWEMainView.swift:57-64`）；「设置」窗口只能 ⌘, 或从 Advanced 工具栏打开（`TBDisplaySenderContentView.swift:52`）；「关于」在 `PWEMainView.swift:319`、`ContentView:46,32`、`TBDisplaySenderSettingsView.swift:117` 各有一份。用户不知道哪个说了算。
2. **画质有四个入口、两套记忆。** PWE「画面」菜单按 iMac 记 preset（`PWESenderModel.swift:464`）；设置表单里还有 Display profiles 三个按钮（`ContentView:606-616`，上游另记一份）、Stream profile 全部预设（`:628-636`）、Match render to stream（`:668`）。新 iMac 默认仍是 1440p（`PWESenderModel.swift:465`）。
3. **连接时设置变灰，规则互相矛盾。** 表单几乎全是 `.disabled(session.isConnected || session.isStreaming)`（`ContentView:568-680`）；键鼠角色反过来只在连接时可改（`:698,:712`）；附加功能开关连接时锁住（`SettingsView:198`）；主窗口「画面」却能在连接中改并自动重连。
4. **声音开关的说法和实际不符，控件分散。** 开关写「用 iMac 的扬声器播放声音」（`PWEStrings.swift:82`），实际两边同时响（基线第 11 条）；只在连接前显示（`PWEMainView.swift:166`）；音量只在 Advanced（`ContentView:221,346`）；总开关在第三个窗口的附加功能卡片里。
5. **设置窗口浅色模式下看不清。** 背景固定深色渐变（`SettingsView:138`），没像表单那样强制深色外观（`ContentView:872`），深底深字。附加功能开关的开和关几乎分不出；卡片标着「Version 3.0」，App 是 1.1。
6. **语言选择不像 Mac App。** 设置窗口有五种语言（`SettingsView:46`），PWE 窗口只做了中英（`PWEStrings.swift:12`）。系统首选 en-AU，`fd.tbdisplaysender.language` 却是 `chinese`（2026-10-19 实查），所以界面白天英文、后来中文；谁点的未核实。
7. **满屏工程术语。** 「operational dashboard」、三行静态的「行为」说明（`SettingsView:63-73`）、导入 JSON 附加功能、verbose 日志；表单每行标签出现两次，如「Transport Transport」（`ContentView:558-559`）；iMac 名字显示成「PWE iMac Display LL-iMac-2017.local」（`PWESenderModel.swift:288` 退回 serviceName）。
8. **菜单栏还是工程师菜单。** 「新增会话 / 全部停止 / 连接信息（IP）」（`TBDisplaySenderStatusItemController.swift:178-213`）；「显示主窗口」把所有窗口叫到前面，主窗口关了也不重开（`:373-379`）。和计划的「菜单栏优先」相反。

## 二、建议的 1.1 结构

**菜单栏（日常）**：状态一行、亮度、夜览和原彩；画面子菜单（5K 60 / 5K 48 / 标准）；声音子菜单（只在 iMac 播放 / 两边都播放 / 只在这台 Mac）；断开或连接、排列显示器…、设置…、退出。去掉会话和 IP。

**主窗口（首次设置和状态）**：保留现有阶段；连接后只放亮度、排列显示器、断开。「自动连接」「登录时打开」在首次设置最后一屏问一次，以后进设置。去掉顶部「高级设置…」。

**一个设置窗口**（PWE 自己写，⌘, 打开，系统外观，标准 Form 加分页）：

| 分页 | 内容 |
|---|---|
| 通用 | 登录时打开、接上线自动连接、菜单栏图标、检查更新。语言跟随系统（macOS「App 语言」），去掉应用内语言选择 |
| 显示 | 画面（按 iMac 记住；默认值等 Lee 定，建议 iMac18,3 默认 5K 60）、镜像或扩展、防止屏保、大光标 |
| 声音 | 上面三个选项；音量跟系统音量键 |
| 键盘与鼠标 | 默认关，标「实验」；打开时按角色说明要哪项权限、在哪台机器上授权 |
| 高级 | Network Link（「也允许通过网线或 Wi‑Fi 连接，实验」）、视频压缩、渲染匹配；诊断：检查配置、线缆测试、重启采集、导出报告；「打开完整控制台」= 上游仪表盘 |

规则：连接中也能改设置，改了自动重连并提示一句；只留 PWE 的「关于」；上游设置窗口和附加功能卡片不再出现在界面上。
