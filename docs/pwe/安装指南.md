# PWE Screen Encore 安装指南

让 5K iMac 返场：把 2014–2017 年的 5K iMac 变成新 Mac 的外接显示器。适用于 PWE Screen Encore 1.1。
1.1 之前它叫 PWE iMac Display。

> 这份指南只适用于 PWE 签名的版本。仓库根目录的 `README.md` 是 TargetBridge 上游的说明，其中的下载地址和 `xattr` 步骤不适用于本版本。

## 你需要

| | 要求 |
|---|---|
| 新 Mac（发送端） | Apple 芯片或 Intel，macOS 14 或更新 |
| iMac（接收端） | 5K iMac，macOS 11 或更新 |
| 线 | 雷雳 3、4 或 5 的线都可以，1 米以内的通常是无源线，最稳 |
| 转换器 | 只有 2014、2015 款 iMac 需要：Apple 的「雷雳 3（USB-C）转雷雳 2 转换器」 |

> ⚠️ 不要用普通的 USB-C 转 Mini DisplayPort 转换器。它只传画面信号，不传雷雳数据，两台电脑连不上。

> ⚠️ 截至 2026-10-16，还没在真实的 Intel iMac 上运行过。我们在 Apple 芯片上和 Rosetta 下测过。遇到问题请开 issue，写明 iMac 型号和系统版本。

## 安装

> ⚠️ 如果装过 PWE iMac Display（本 App 的旧名），先把旧版移到废纸篓：新 Mac 和 iMac 上各一个。两份同时留着，系统可能打开旧的那一份。设置和配对记录不随旧 App 删除，新版会接着用。

1. 在新 Mac 上打开 `PWE-Screen-Encore-<版本>.dmg`。
2. 把「PWE Screen Encore」拖进「应用程序」。
3. 把「PWE Screen Encore Receiver」拷进 iMac 的「应用程序」。U 盘、隔空投送、文件共享都可以。
4. 在 iMac 上从「应用程序」打开 PWE Screen Encore Receiver。
   成功判据：屏幕中间显示 PWE Screen Encore 的图标、名字和「等待 Mac 连接」。
5. 第一次打开时，接收端会问「开机后自动打开接收端吗？」。推荐选「自动打开」。
   如果是直接从 DMG 里打开的，它不会问；拷进「应用程序」再打开就会问。
6. 在新 Mac 上打开 PWE Screen Encore。
7. 第一次打开时，主窗口显示「允许录屏」。点「打开系统设置」，在「隐私与安全性」里允许 PWE Screen Encore。
   这一项在 macOS 15 及以后叫「录屏与系统录音」，在 macOS 14 叫「屏幕录制」。
8. 回到 PWE Screen Encore。成功判据：主窗口变成「正在找你的 iMac」。
   如果还停在「允许录屏」，点「重新打开 PWE Screen Encore」。

两个 App 都经过 Apple 公证，正常情况下打开时不会有安全警告。如果出现「已损坏」或「无法验证开发者」：

1. 确认文件来自 GitHub 的 release 页面或 Homebrew。
2. 在终端运行 `shasum -a 256 PWE-Screen-Encore-<版本>.dmg`，和 release 页面上 `SHA256SUMS.txt` 里的值对比。
3. 如果两者一致仍然报警告，请开一个 issue，附上 macOS 版本和警告截图。不要用 `xattr` 命令绕过检查。

用 Homebrew 的话，在新 Mac 上运行：

```bash
brew install --cask kenshinice-ai/tap/pwe-imac-display
```

它会把两个 App 都装进「应用程序」。接收端仍然要拷到 iMac 上。

## 连接

1. 用雷雳线连接两台电脑。
2. 看新 Mac 上 PWE Screen Encore 的主窗口。几秒后 iMac 会自己出现。
   - 如果只有一台 iMac，直接点「用作显示器」。
   - 如果有几台，先在「选择你的 iMac」里点一台，再点「用作显示器」。
3. 成功判据：几秒后 iMac 显示新 Mac 的画面，主窗口显示「……正在用作显示器」。
4. 点「排列显示器…」，在「系统设置 > 显示器」里把 iMac 拖到它实际摆放的位置。

iMac 一直不出现时，可以手动填 IP：在菜单栏图标里选「设置…」，到「高级」页点「完整控制台」的「打开…」，在「接收端」一栏选「手动输入」，填 iMac 的 IP。
IP 在 iMac 画面底部的小字里；按 I 可以看到完整的详细信息。

## 日常使用

- **接上线就自动连接：** 第一次连接成功后，PWE Screen Encore 会记住这台 iMac。以后它一出现在雷雳线上，就自动连成显示器。
  在主窗口或菜单栏点「断开」，或在完整控制台里停止后，本次不再自动连接；拔线再插上，或退出后重新打开 App，会恢复自动连接。
  不想要可以在「设置… › 通用」里关掉「接上线就自动连接」。
- **新 Mac 登录时打开：** 第一次连上时，主窗口里的「登录时打开」默认勾上；以后在「设置… › 通用」里改。如果下面出现「在『登录项』里允许…」，点它并在系统设置里允许。
- **iMac 开机自动打开接收端：** 在 iMac 的接收端画面按 I 查看详情，再按 A 切换。详情里会显示「开机自动打开：开」或「关」。
- **接收端画面：** 等待时只显示名字和一句提示；按 I 显示 IP、状态和权限等详细信息，再按 I 返回。
- **亮度、音量、画面、声音：** 都在菜单栏图标里。
- **用亮度键调 iMac：** 在「设置… › 通用」里打开「用亮度键调 iMac」。指针在 iMac 上时，按 F1、F2 调 iMac 的亮度。
  有触控栏的 Mac：按住 fn 再按 F1 或 F2。触控栏上的亮度按钮只调这台 Mac（2026-10-20 在 MacBook Pro M1 上实测）。
- **完整控制台：** 「设置… › 高级」里的「完整控制台」打开 TargetBridge 自己的控制台，可以调码流、编码、多台接收端等。

## 推荐设置

- 菜单栏「画面」里选「扩展显示」，iMac 就是一块扩展屏。选「镜像显示」会显示和主屏一样的内容。
- 声音在菜单栏「声音」里选：「只在 iMac 播放」「两边都播放」或「只在这台 Mac 播放」。
- 画质在菜单栏「画面」里选，每台 iMac 各记各的：「5K · 60 Hz」最流畅；画面卡顿时选「标准 · 1440p」。

## 遇到问题

**找不到 iMac**
1. 确认 iMac 上的接收端开着，画面显示「等待 Mac 连接」。
2. 如果 iMac 是 macOS 15 或更新：在 iMac 的「系统设置 › 隐私与安全性 › 本地网络」里，打开 PWE Screen Encore Receiver。
3. 在「设置… › 高级」的「诊断」里点「检查配置」，按提示处理。
4. 在完整控制台里用「手动输入」填 iMac 的 IP。

**画面卡或模糊**
1. 在完整控制台里点「运行线缆测试」。如果速率明显低于线的标称值，换一根线或换一个接口。
2. 在菜单栏「画面」里降一档，例如「标准 · 1440p」。

**权限明明打开了，App 还说没有权限**

从测试版或 TargetBridge 换成本版本后可能出现：「系统设置」里的开关是开的，但存的是旧 App 的记录。症状是连不上，或者 iMac 上鼠标能动、不能点。

1. 按 `⌘Q` 退出「系统设置」。只关窗口不够，它会把旧记录写回去。
2. 重新打开「系统设置 > 隐私与安全性」，在「录屏与系统录音」（接收端是「辅助功能」和「输入监控」）里选中这个 App，点「−」删掉。
3. 点「+」把「应用程序」里的这个 App 加回来，打开开关。
4. 退出这个 App，再打开。

成功判据：App 不再提示缺少权限，iMac 出画面；键鼠共享时 iMac 上能点击。

**iMac 上的文字太小或太大**
在新 Mac 的「系统设置 > 显示器」里选中 iMac，换一个分辨率。

**iMac 上的界面是英文**
在 iMac 的接收端界面按 L 键，可以切换语言。

**一边用「屏幕共享」看着这台 Mac，一边换画面，Mac 锁屏了**

换画面、插拔雷雳线时，iMac 这块显示器会断开再接上。我们测试时看到：如果这时正有别的电脑用「屏幕共享」看着这台 Mac，那次共享会话会跟着结束，macOS 随即锁屏（系统日志里锁屏是「屏幕共享」发起的，不是本 App）。

1. 在这台 Mac 上解锁。
2. 如果要边远程看边测试，先结束屏幕共享，再换画面或插拔线；或者让屏幕共享走 Wi‑Fi，不走雷雳线。

**其他问题**
请到 https://github.com/kenshinice-ai/pwe-imac-display/issues 开一个 issue，或写信到 support@pwestudio.site。写明三件事：两台电脑的型号、各自的 macOS 版本、出问题前做了什么。

## 局域网模式

接收端默认只接受经雷雳线（或 USB 直连线）连过来的 Mac。同一个 Wi-Fi 或局域网里的其他电脑连不上它。

如果你确实要用 Wi-Fi 或以太网连接（发送端的实验功能 Network Link）：

1. 先用雷雳线连接，让这台 Mac 和 iMac 配对一次。配对只能经线完成。
2. 在 iMac 的终端里运行：

   ```bash
   defaults write com.pwegroup.pweimacdisplay.receiver AllowLocalNetwork -bool true
   ```

3. 退出并重新打开接收端。
4. 拔掉雷雳线，在新 Mac 上用 Network Link 连接 iMac。成功判据：iMac 出画面。

经 Wi-Fi 或局域网的连接总是加密的，只有已配对的 Mac 能连上。「允许不加密连接」只对线缆有效。

恢复默认：运行下面的命令，再退出并重新打开接收端。

```bash
defaults delete com.pwegroup.pweimacdisplay.receiver AllowLocalNetwork
```

> ⚠️ 只在可信的网络里打开局域网模式。否则同一网络里的电脑都能发现这台 iMac，并可能妨碍你的 Mac 连上它。原因：接收端一次只接一台 Mac，要先接受连接才能确认对方是否配对过。

## 卸载

1. 在新 Mac 的「设置… › 通用」里关掉「登录时打开」，再退出 PWE Screen Encore。
2. 在 iMac 的接收端画面按 I，确认显示「开机自动打开：关」；如果是「开」，按 A 关掉。然后退出接收端。
3. 把两个 App 分别从两台电脑的「应用程序」移到废纸篓。

如果已经先删了接收端，iMac 每次开机可能仍会尝试打开它：
- macOS 11、12：删掉 `~/Library/LaunchAgents/com.pwegroup.pweimacdisplay.receiver.plist`。
- macOS 13 及以后：在「系统设置 > 通用 > 登录项」里移除它。

用 Homebrew 装的，在新 Mac 上运行 `brew uninstall --cask --zap pwe-imac-display`。
