# PWE iMac Display 安装指南

把 2014–2017 年的 5K iMac 变成新 Mac 的外接显示器。适用于 PWE iMac Display 1.1。

> 这份指南只适用于 PWE 签名的版本。仓库根目录的 `README.md` 是 TargetBridge 上游的说明，其中的下载地址和 `xattr` 步骤不适用于本版本。

## 你需要

| | 要求 |
|---|---|
| 新 Mac（发送端） | Apple 芯片或 Intel，macOS 14 或更新 |
| iMac（接收端） | 5K iMac，macOS 11 或更新 |
| 线 | 雷雳 3、4 或 5 的线都可以，1 米以内的通常是无源线，最稳 |
| 转换器 | 只有 2014、2015 款 iMac 需要：Apple 的「雷雳 3（USB-C）转雷雳 2 转换器」 |

> ⚠️ 不要用普通的 USB-C 转 Mini DisplayPort 转换器。它只传画面信号，不传雷雳数据，两台电脑连不上。

> ⚠️ 1.0 还没在真实的 Intel iMac 上运行过。我们在 Apple 芯片上和 Rosetta 下测过端到端流程。遇到问题请开 issue，写明 iMac 型号和系统版本。

## 安装

1. 在新 Mac 上打开 `PWE-iMac-Display-1.0.0.dmg`。
2. 把「PWE iMac Display」拖进「应用程序」。
3. 把「PWE iMac Display Receiver」拷到 iMac 上，放进 iMac 的「应用程序」。U 盘、隔空投送、文件共享都可以。
4. 在 iMac 上打开 PWE iMac Display Receiver。成功判据：屏幕上显示「PWE iMac Display 接收端」和一个 IP 地址。
5. 在新 Mac 上打开 PWE iMac Display。
6. 第一次打开时，按提示在「隐私与安全 > 录屏与系统录音」里允许 PWE iMac Display，然后按提示重新打开它。

两个 App 都经过 Apple 公证，正常情况下打开时不会有安全警告。如果出现「已损坏」或「无法验证开发者」：

1. 确认文件来自 GitHub 的 release 页面或 Homebrew。
2. 在终端运行 `shasum -a 256 PWE-iMac-Display-1.0.0.dmg`，和 release 页面上 `SHA256SUMS.txt` 里的值对比。
3. 如果两者一致仍然报警告，请开一个 issue，附上 macOS 版本和警告截图。不要用 `xattr` 命令绕过检查。

用 Homebrew 的话，在新 Mac 上运行：

```bash
brew install --cask kenshinice-ai/tap/pwe-imac-display
```

它会把两个 App 都装进「应用程序」。接收端仍然要拷到 iMac 上。

## 连接

1. 用雷雳线连接两台电脑。
2. 在新 Mac 的 PWE iMac Display 里，看「接收端」一栏。
   - 如果「已发现的接收端」里有 iMac，就选它。
   - 如果没有，就选「手动输入」，填 iMac 屏幕上显示的 IP。
3. 点「连接」。成功判据：几秒后 iMac 进入全屏，显示新 Mac 的画面。
4. 在新 Mac 的「系统设置 > 显示器」里，把 iMac 拖到它实际摆放的位置。

## 日常使用（1.1 起）

- **接上线就自动连接：** 第一次连接成功后，PWE iMac Display 会记住这台 iMac。以后只要它出现在雷雳线上，就自动连接成扩展屏。在主窗口点「断开」后，本次不再自动连接；拔线再插上，或下次登录，会恢复自动连接。不想要可以在主窗口底部关掉「接上线就自动连接」。
- **登录时打开：** 在新 Mac 的主窗口底部打开「登录时打开」。
- **iMac 开机自动等待：** 接收端第一次打开时会问「开机后自动打开接收端吗？」。以后要改，在接收端画面上按 I 查看详情，再按 A 切换。
- **接收端画面：** 等待时只显示名字和一句提示；按 I 显示 IP、状态和权限等详细信息，再按 I 返回。
- **高级设置：** 主窗口右上角的「高级设置…」打开完整的 TargetBridge 控制台，可以调码流、编码、多台接收端等。

## 推荐设置

- 来源选「扩展桌面」，iMac 就是一块独立的屏。选「镜像桌面」会显示和主屏一样的内容。
- 「显示配置」先选「5K 办公」。如果画面卡顿，选「低延迟」，或在「码流配置」里改用「流畅」或「流畅+」。
- 「视频压缩」保持「自动（推荐）」。
- 想让 iMac 的扬声器出声，打开「传输音频」。

## 遇到问题

**找不到接收端**
1. 确认两台电脑都开着各自的 App。
2. 在 PWE iMac Display 里找到「引导式配置检查」，点「检查配置」，按提示处理。
3. 用「手动输入」填 iMac 上显示的 IP。

**画面卡或模糊**
1. 点「运行线缆测试」。如果速率明显低于线的标称值，换一根线或换一个接口。
2. 把「码流配置」降一档。

**iMac 上的文字太小或太大**
在新 Mac 的「系统设置 > 显示器」里选中 iMac，换一个分辨率。

**iMac 上的界面是英文**
在 iMac 的接收端界面按 L 键，可以切换语言。

**其他问题**
请到 https://github.com/kenshinice-ai/pwe-imac-display/issues 开一个 issue。写明三件事：两台电脑的型号、各自的 macOS 版本、出问题前做了什么。
