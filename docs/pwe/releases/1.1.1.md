# PWE Screen Encore 1.1.1

发布 2026-10-29 · 构建号 `20261029111139` · DMG sha256 `431227efdb1ca41725432105713a9aebc88700536d32c3278ec475e944e77368`

PWE Screen Encore 把 2014–2020 年的 27 英寸 5K iMac 变成新 Mac 的外接显示器，一根雷雳线。

## 中文

**更新**：Mac 和 iMac 两边都换成 1.1.1。设置和已经配好的连接都会保留。用 Homebrew 的：先运行 `brew trust kenshinice-ai/tap`，再 `brew upgrade --cask pwe-screen-encore`。

**画面**
- 「画面」菜单新增「流畅 · 4K 60」：桌面大小不变，传输改用 4K，快速动画更顺，文字略软一点。「标准 · 1440p」改为每秒 60 帧。
- 这台 Mac 跑「5K · 60 Hz」跟不上时，菜单里会出一行灰字建议。只建议，不会自动换。
- iMac 默认用 Metal 显示画面。以前在设置里选过的，保持你的选择。
- 卡顿之后直接显示最新的画面，不再快进补帧。
- 没有 HEVC 硬件解码的 iMac，软件解码会用上多个核心。
- 用过完整控制台的，画面档位不再被它的「渲染匹配」设置带偏。

**只接 iMac 的 Mac**（例如 Mac mini、Mac Studio）
- 第一次连接也能在 iMac 上完成，不用另接一台显示器。
- 设置 › 通用 新增「以后只用 iMac」：一张清单，趁还看得见这台 Mac 时做一次。
- 扩展模式下换了一种抓屏方式。如果你觉得不如 1.1.0，在「终端」运行下面这行，再断开重连，就回到 1.1.0 的方式：
  `defaults write com.pwegroup.pweimacdisplay PWEDirectCaptureExtended -bool false`

**连接与使用**
- 用 iMac 控制这台 Mac 时，键盘鼠标单独处理，画面卡一下时指针也不停。
- 只有声音真的送到 iMac 时，才把 Mac 自己静音。声音中断恢复后会再自动重试。
- 屏幕睡眠、系统睡眠之后，状态显示和画面恢复更可靠。
- iMac 上调亮度只改接收端所在的那块屏。
- 「登录时打开」显示真实状态；屏幕共享正在显示 iMac 时会提示。

**隐私与求助**
- 不再记录键盘输入的调试信息。旧版本留下的这类日志会自动删除。
- 「保存报告…」总会附上 Mac 端的日志，并去掉重复的行。
- iMac 上接收端用到的库放在 `~/Library/Caches`。

**已验证**：MacBook Pro 13 M1（macOS 27.2）+ 2017 款 27 英寸 5K iMac（iMac18,3，macOS 13.7.8）：从上一版升级不用重新配对；睡眠唤醒；10 分钟连续使用不掉线；5K 跟不上时出建议、画面静止时不误判；「流畅 · 4K 60」；指针在两块屏之间来回。Mac Studio M1 Ultra 只接 iMac：FileVault 开机后用 iMac 的键盘解锁。

**未验证**：没有在 M4 系列 Mac 上测过 1.1.1。2014、2015、2019、2020 款和 iMac Pro 仍没有真机结果，欢迎用「机型回报」issue 告诉我们。

**已知**：M1 这一代的 Mac 在 5K 下跑全屏快速动画会有一点顿，菜单会建议「流畅 · 4K 60」。用 iMac 控制 Mac、Mac 自己的屏也开着时，指针可以走到 Mac 自己的屏上；在 iMac 上找不到它时，往 iMac 那边移回来。

## English

**Updating**: update both the Mac and the iMac to 1.1.1. Settings and existing connections are kept. With Homebrew, run `brew trust kenshinice-ai/tap` first, then `brew upgrade --cask pwe-screen-encore`.

**Picture**
- New in the Picture menu: Smooth · 4K 60. The desktop keeps its size; the stream is sent at 4K, so fast motion is smoother and text is slightly softer. Standard · 1440p now runs at 60 frames per second.
- When this Mac can't keep up with 5K · 60 Hz, the menu shows a grey suggestion. It only suggests; it never switches for you.
- The iMac now draws with Metal by default. If you chose a renderer in Settings before, your choice stays.
- After a stall the iMac shows the newest picture instead of fast-forwarding through the backlog.
- iMacs without HEVC hardware decode use several cores for software decode.
- If you used the full console, its render-matching setting no longer bends the picture size.

**Macs connected only to the iMac** (a Mac mini or Mac Studio, for example)
- The first connection can be completed on the iMac; no second display needed.
- Settings › General › Use only the iMac: a short checklist to do once while you can still see this Mac.
- Extended mode captures the screen a different way. If it feels worse than 1.1.0, run this in Terminal, then disconnect and reconnect to go back to the 1.1.0 way:
  `defaults write com.pwegroup.pweimacdisplay PWEDirectCaptureExtended -bool false`

**Connecting and using**
- When the iMac controls this Mac, keyboard and mouse are handled on their own, so the pointer keeps moving if the picture hitches.
- This Mac mutes itself only while its sound is really going to the iMac. Sound retries again after it recovers from a drop.
- Display sleep and system sleep recover more reliably, and the status says what is happening.
- Brightness changes on the iMac touch only the display the receiver is on.
- Open at login shows its real status; Screen Sharing showing the iMac gets a notice.

**Privacy and support**
- Keyboard input is no longer written to debug logs. Such logs left by earlier versions are removed automatically.
- Save Report… always includes the Mac's own log, without repeated lines.
- The receiver keeps its libraries in `~/Library/Caches`.

**Verified**: MacBook Pro 13 M1 (macOS 27.2) + 2017 27-inch 5K iMac (iMac18,3, macOS 13.7.8): upgrading from the previous version without pairing again; sleep and wake; ten minutes of continuous use without a drop; the 5K suggestion appears when the Mac falls behind and not when the picture is still; Smooth · 4K 60; the pointer moving between both displays. Mac Studio M1 Ultra connected only to the iMac: FileVault unlocked at startup with the iMac's keyboard.

**Not verified**: 1.1.1 has not been tested on an M4-series Mac. Still no hardware results for 2014, 2015, 2019, 2020 models or iMac Pro; a "Model report" issue helps.

**Known**: M1-generation Macs stutter a little with full-screen fast motion at 5K; the menu suggests Smooth · 4K 60. When the iMac controls the Mac and the Mac's own screen is on, the pointer can move onto the Mac's screen; if you can't find it on the iMac, move it back toward the iMac.
